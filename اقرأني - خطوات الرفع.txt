خطوات رفع «راسم الدوال» على GitHub Pages (مرة واحدة فقط)
=========================================================

1) ادخل حسابك على github.com (roshdy1221985).
2) اضغط New repository، واكتب الاسم بالظبط:  rasem-dawal
   (لازم الاسم يكون كده حرفيًا، لأن ملف الإضافة مكتوب فيه الرابط ده)
   اختار Public واضغط Create repository.
3) اضغط  uploading an existing file  واسحب كل محتويات المجلد ده:
      index.html
      manifest.xml
      مجلد assets (فيه الأيقونات)
   ثم اضغط Commit changes.
4) من Settings ← Pages ← Branch اختار main و /(root) ← Save.
5) استنى دقيقتين، وهيبقى رابط الأداة:
      https://roshdy1221985.github.io/rasem-dawal/
   وده نفس الرابط اللي ملف الإضافة بيفتحه جوه Word.

ملاحظات:
- ملف manifest.xml هو اللي المدرس بيثبته في Word (والأداة نفسها فيها زر يحمّله).
- لما تحدّث الأداة بعدين: ارفع index.html الجديد مكان القديم بس، والإضافة في Word هتتحدث لوحدها عند كل المدرسين.
- ماترفعش أبدًا: «مصدر راسم الدوال» ولا «مولد أكواد راسم الدوال».
